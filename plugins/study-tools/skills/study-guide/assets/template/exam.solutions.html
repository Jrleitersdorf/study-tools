Model answer

Each half-life multiplies what is left by one half, and \(t/t_{1/2}\) half-lives have passed, so the fraction left is \((1/2)^{t/t_{1/2}}\).

def fraction_left(t, half_life):
    return 0.5 ** (t / half_life)

print(round(fraction_left(20, 8), 3))   # 0.177

\(20/8=2.5\) half-lives, so the call returns \((1/2)^{2.5}\approx0.177\). Writing math.exp(-math.log(2) * t / half_life) is the same function.

  • Uses the decay law: one half raised to the number of half-lives, or the equivalent exponential.
  • Divides the time by the half-life (not multiplying, and not subtracting), and returns the value rather than printing it.
  • Gives about 0.177 for fraction_left(20, 8).
